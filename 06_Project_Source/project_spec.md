# Coffee_Atlas｜專案規格紀錄

## 專案識別
- 專題：THE COFFEE ATLAS｜咖啡世界圖鑑
- 受眾：一般大眾至咖啡初學者
- 課程：生成式AI：文字與圖像生成的原理與實務
- 學校：國立暨南國際大學
- 系級：資訊管理學系碩士班一年級

## Wiki
- 五冊、11 個核心主題。
- Markdown 知識筆記＋單一 HTML 閱讀介面。
- 復古研究手帳視覺；繁體中文解說、英文標題與專業名詞中英對照。
- 依主題調整內容深度；段落引用＋章節末 APA 7th。
- 搜尋、收藏、圖片放大、術語查詢、抽屜目錄、閱讀進度、字體與深淺色切換、前後章、列印等互動。

## HTML 雜誌
- 30 頁教學內容，另含封面與目錄，共 32 頁。
- 圖片優先、復古咖啡雜誌風格。
- 側邊標籤、滾輪／觸控捲動、鍵盤切頁及全螢幕。
- 涵蓋世界產地、品種、處理、烘焙、風味、器材、手沖、義式、搭配、選豆、迷思與術語。

## 資料來源
- 15 筆：學術 8、官方／研究機構 5、專業產業 2。
- 中英文混合；學術研究以英文為主；新舊研究並重。
- APA 7th，保留 DOI 或原始網址。

## AI 工作流程與驗收
- Graph＋Loop 混合流程。
- 六項檢查：知識正確性、引用來源、內容完整性、Wiki／簡報一致性、視覺排版、網站功能。
- 最多兩輪修正；未通過項目列出並人工確認。
- 不虛構瀏覽器測試結果。
